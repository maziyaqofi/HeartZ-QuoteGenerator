# 💔 HeartZ
HeartZ is a modern quote generator web application designed for Gen Z emotions, relationships, heartbreaks, and late-night thoughts.
This platform provides random emotional quotes inspired by songs, love stories, heartbreak experiences, and relationship vibes from different languages and cultures.

## ✨ Features
- Random quote generator
- Filter quotes by categories
- Song & artist source display
- Aesthetic glassmorphism UI
- Blur popup modal effect
- Relationship & heartbreak vibes
- Multi-language categories: Bollywood, English, Indonesia, Jawa, Arab

## 🎨 UI Style
HeartZ uses:
- Glassmorphism design
- Soft gradients
- Blur effects
- Emotional aesthetic experience
- Modern Gen Z inspired interface

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
